# ⚽ מונדיאל ניחושים

מערכת ניחושים מלאה בעברית למונדיאל — לחברים בעבודה. הרשמה בקוד, ניחוש תוצאות, ניקוד אוטומטי, **טבלת דירוג חיה** ותוצאות בלייב, בעיצוב מודרני בסגנון אפליקציות הספורט (כמו 365).

## ✨ מה יש במערכת

- **הרשמה בקוד** — מנהל פותח תחרות ומקבל קוד בן 6 תווים. כל חבר נרשם בעצמו עם הקוד והשם שלו.
- **ניחוש תוצאות** — כל משתתף מנחש את התוצאה המדויקת של כל משחק. הניחוש נשמר אוטומטית ונסגר עם שריקת הפתיחה.
- **ניקוד אוטומטי (בסגנון טוטו):**
  | תוצאה | נקודות |
  |------|--------|
  | ניחוש מדויק | **5** |
  | כיוון נכון + הפרש שערים נכון | **3** |
  | כיוון נכון (מנצחת/תיקו) | **1** |
  | החטאה | 0 |
- **תוצאות בלייב** — המנהל מסמן משחק כ"חי" ומעדכן תוצאה; כל המשתתפים רואים עדכון מיידי (ללא רענון) דרך Server-Sent Events.
- **טבלת דירוג חיה** — פודיום למובילים, הדגשת השורה שלך, סטטיסטיקות (משחקים, מדויקים, פגיעות) ומיון אוטומטי לפי נקודות ⇽ ניחושים מדויקים.
- **דגלים ותמונות** — דגל לכל נבחרת (תמונה עם נפילה לאימוג'י כשאין רשת).
- **מסך ניהול** — הוספה/עריכה/מחיקה של משחקים, עדכון תוצאות, ושיתוף קוד ההזמנה.
- **ניחושי הקבוצה** — אחרי שמשחק נסגר אפשר לראות מי ניחש מה.

המערכת מגיעה עם **מערכת משחקים לדוגמה מוכנה לשימוש** (שלב הבתים), שאפשר לערוך לגמרי ממסך הניהול.

## 🚀 הפעלה

```bash
npm install
npm start
```

ואז גלשו אל http://localhost:3000

> דורש Node.js 18 ומעלה. אין צורך בהתקנת מסד נתונים — הנתונים נשמרים בקובץ `data/db.json`.

### משתני סביבה (אופציונלי)
- `PORT` — פורט ההאזנה (ברירת מחדל 3000)
- `DATA_DIR` — תיקיית שמירת הנתונים (ברירת מחדל `./data`)

## 📱 איך משתמשים

1. **המנהל**: פותח תחרות בלשונית "פתיחת תחרות", מקבל קוד.
2. **החברים**: נכנסים לאותו אתר, לוחצים "הצטרפות בקוד", מזינים את הקוד והשם.
3. כולם מנחשים תוצאות לפני המשחקים.
4. **המנהל** מעדכן תוצאות במסך הניהול → הניקוד והטבלה מתעדכנים אצל כולם בזמן אמת.

## 🌐 פריסה (Deploy)

האפליקציה היא שרת Node יחיד שמגיש גם את ה-frontend, וקל לפרוס אותה לכל שירות
(Render / Railway / Fly.io / VPS):

```bash
npm install && npm start   # פקודת ההפעלה
```

הקפידו על תיקיית `DATA_DIR` קבועה (volume) כדי שהנתונים יישמרו בין הפעלות.

## 🛠️ מבנה הפרויקט

```
server.js          – שרת Express: API, אימות, ניקוד ועדכונים חיים (SSE)
lib/db.js          – אחסון JSON פשוט עם כתיבה אטומית
lib/scoring.js     – חוקי הניקוד
lib/seed.js        – נבחרות ותבנית משחקים
public/            – ה-frontend (HTML/CSS/JS, ללא שלב build)
```
