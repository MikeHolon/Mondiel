# 🛒 סל חכם — רשימת קניות לסופר

אפליקציית ווב (PWA) בעברית לניהול קניות בסופר, בנויה כאתר סטטי בלי צורך בשרת.

## ✨ מה יש בפנים

- **הוספת מוצרים בכל דרך** — הקלדה חופשית עם השלמות, סריקת ברקוד 📷 במצלמת הטלפון, או הדבקת רשימה שלמה 📋 (שורה לכל מוצר).
- **זיהוי חכם של כמות ויחידה** — מקלידים `2 ק"ג עגבניות` או `500 גרם גבינה צהובה` והאפליקציה מפרקת לבד לשם, כמות ויחידה. יחידות נתמכות: יח', ק"ג, גרם, ליטר, מ"ל, אריזה, שקית, בקבוק, קופסה, שישייה — עם קפיצות כמות מותאמות לכל יחידה.
- **חלוקה אוטומטית לקטגוריות** — ירקות ופירות, חלב וביצים, בשר ודגים, מזווה, קפואים, ניקיון ועוד, לפי סדר הליכה טבעי בסופר.
- **🔴 קניות לייב ביחד** — פותחים חדר, שולחים קישור בוואטסאפ, ושני הטלפונים מסונכרנים בזמן אמת: כל סימון ✔ או הוספה מופיעים מיד אצל שניכם.
- **🧑‍🤝‍🧑 מצב חלוקה בסופר** — משייכים כל מוצר ל"אני" או לבת/בן הזוג ומסננים כך שכל אחד רואה את החלק שלו.
- **💰 השוואת מחירים** — הערכת עלות הסל בשופרסל, רמי לוי, ויקטורי, יוחננוף ואושר עד לפי מחירון הדגמה מובנה, עם קישור לבדיקת מחיר אמיתי ב־[CHP](https://chp.co.il) (מבוסס נתוני שקיפות המחירים הרשמיים).
- **עובד גם בלי קליטה** — Service Worker שומר את האפליקציה במטמון, והרשימה נשמרת מקומית בטלפון.
- **התקנה כאפליקציה** — "הוסף למסך הבית" מהדפדפן.

## 🚀 הפעלה

זהו אתר סטטי — כל שרת קבצים מתאים:

```bash
# מקומית
python3 -m http.server 8080
# ואז לגלוש אל http://localhost:8080
```

או לפרוס ב־GitHub Pages: הגדרות הריפו → Pages → הגשה מה־branch.

> **חשוב:** סריקת ברקוד וסנכרון לייב דורשים HTTPS (או localhost) בגלל הרשאות מצלמה בדפדפן.

## 🏗️ מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | המסך הראשי וכל הדיאלוגים |
| `js/app.js` | לוגיקת הרשימה, פענוח טקסט, רינדור |
| `js/data.js` | קטגוריות, יחידות, קטלוג מוצרים ומחירי הדגמה |
| `js/scanner.js` | סריקת ברקוד (BarcodeDetector מובנה, ZXing כגיבוי) |
| `js/sync.js` | סנכרון לייב בין מכשירים (MQTT over WebSocket) |
| `sw.js` | עבודה בלי אינטרנט |

## 📝 הערות

- **מחירים**: המחירים המובנים הם להדגמה בלבד ומשתנים בין סניפים ותאריכים. לחיבור מחירים אמיתיים אפשר להוסיף שרת שקורא את קבצי שקיפות המחירים שהרשתות מפרסמות לפי חוק.
- **לייב**: הסנכרון עובר דרך ברוקר MQTT ציבורי עם קוד חדר אקראי — נוח לזוג, לא מיועד למידע רגיש.
